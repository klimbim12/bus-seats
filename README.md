# 현장체험학습 버스 좌석 배치

학생 명단(나이스 명렬표 가져오기 지원) → 희망 친구 1·2·3지망 · 멀미 학생 → 짝꿍 규칙 · 교사 좌석 → 희망순 자동 배치와 직접 옮기기.

- **웹으로 쓰기**: 이 저장소의 GitHub Pages 주소에서 바로 사용
- **프로그램으로 쓰기**: 오른쪽 **Releases**에서 최신 빌드를 받기
  - 윈도우: `BusSeats-…-win-x64.exe`(설치용) 또는 `BusSeats-…-portable.exe`(설치 없이 실행)
  - 맥: `BusSeats-…-mac-universal.dmg`

## 데이터

- 입력한 내용은 **사용하는 컴퓨터(브라우저)에만** 저장돼요. 이 저장소에는 학생 정보가 올라가지 않아요.
- 다른 컴퓨터로 옮길 때는 화면 맨 아래 **백업 파일 저장 → 백업 파일 불러오기**.
- 백업 파일에는 학생 이름이 들어 있으니 이 저장소에 올리지 마세요.

## 처음 실행할 때 경고가 떠요

코드 서명(유료 인증서)을 하지 않은 프로그램이라서 그래요.

- **윈도우**: "Windows의 PC 보호" → **추가 정보** → **실행**
- **맥**: 앱을 응용 프로그램 폴더로 옮긴 뒤 **Control 키 누른 채 클릭 → 열기 → 열기**.
  "손상되었습니다"가 뜨면 터미널에서 `xattr -cr /Applications/BusSeats.app`

## 새 버전 만들기

`index.html`을 고쳐서 올리면 **Actions**가 자동으로 EXE·DMG를 다시 만들어 Releases에 올려요(약 10분).
